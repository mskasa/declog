# Security Policy

## Supported Versions

Only the latest release is actively maintained.

| Version | Supported |
| ------- | --------- |
| latest  | ✅        |
| older   | ❌        |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub Issues.**

Use [GitHub Security Advisories](https://github.com/mskasa/kizami/security/advisories/new)
to report a vulnerability privately. You will receive a response within 7 days.

Please include as much of the following as possible:

- Description of the vulnerability and its potential impact
- Steps to reproduce
- Affected version(s)
- Any suggested fix, if available

We appreciate responsible disclosure and will credit reporters in the release notes
(unless you prefer to remain anonymous).
